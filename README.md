# 티스토리 건강블로그 자동발행

최신 건강 자료 수집, AI 원고 작성, 대표·본문 이미지 생성, 티스토리 비공개 저장 또는 공개 발행을 한 화면에서 처리하는 로컬 대시보드입니다.

티스토리 Open API가 종료되어 Playwright가 실제 티스토리 글쓰기 화면을 조작합니다. 카카오 계정 아이디와 비밀번호는 코드에 저장하지 않습니다. 대시보드의 **티스토리 로그인** 버튼을 누른 뒤 열린 브라우저에서 사용자가 직접 로그인하면 브라우저 세션만 로컬에 저장합니다.

## 실행

```powershell
npm install
npm start
```

또는 `start-health-blog.cmd`를 실행합니다. 브라우저 주소는 다음과 같습니다.

```text
http://localhost:3000
```

기본 발행 대상은 아래 블로그로 설정되어 있습니다.

```text
https://lalachocho.tistory.com
```

화면 상단의 `발행 대상 · lalachocho` 링크로 블로그를 바로 확인할 수 있습니다. 최초 한 번은 `티스토리 로그인` 버튼을 눌러 해당 블로그를 관리할 수 있는 카카오 계정으로 직접 로그인해야 합니다.

## 사용 순서

1. 우측 상단 **티스토리 로그인**을 누르고 카카오 로그인을 완료합니다.
2. 제휴상품 영역의 **네이버 로그인**을 누르고 브랜드커넥트를 이용하는 네이버 계정으로 로그인합니다.
3. 건강 키워드나 뉴스 링크로 글감을 찾습니다. 제휴상품 검색어를 비워 두면 주제에 맞는 상품을 자동으로 고릅니다.
4. 기본 선택된 `바로 발행`을 사용하거나, 검토 후 직접 발행하려면 `비공개 저장`으로 바꿉니다.
5. 글감을 실행하면 브랜드커넥트에서 실제 상품을 찾고 `naver.me` 제휴 링크를 발급합니다.
6. 원고를 티스토리에 저장한 뒤 오렌지 그라데이션 대표이미지와 본문 이미지를 생성해 같은 글에 배치합니다.
7. 제휴 고지는 글 최상단, 추천 상품 링크는 글 맨 마지막에 자동으로 들어갑니다.
8. `바로 발행`을 선택했다면 이미지 배치 후 공개 발행하고, `비공개 저장`을 선택했다면 비공개 상태로 남깁니다.

## 데이터와 로그인 세션

티스토리 전용 데이터는 기본적으로 프로젝트 상위의 `tistory_blog_data`에 저장됩니다.

- 작업 이력: `tistory_blog_data/drafts`
- 티스토리 세션: `tistory_blog_data/session/tistory-state.json`
- 블로그 프로필: `tistory_blog_data/session/tistory-profile.json`

저장 위치를 바꾸려면 `TISTORY_BLOG_DATA_DIR` 환경변수를 사용합니다. 계정에 여러 티스토리 블로그가 연결돼 있어 자동 선택이 맞지 않는 경우에는 다음 중 하나를 지정할 수 있습니다.

```powershell
$env:TISTORY_BLOG_NAME = '내블로그이름'
# 또는
$env:TISTORY_BLOG_URL = 'https://내블로그이름.tistory.com'
npm start
```

## 주의

- 티스토리 화면 구조가 바뀌면 자동화 셀렉터도 조정해야 할 수 있습니다.
- 발행 실패 시 해당 작업 폴더의 `publish-error.png`와 `logs/server.log`를 확인합니다.
- 자동 발행 전에는 글과 이미지, 제휴 고지 문구를 직접 확인하는 것을 권장합니다.
- 포트 `3000`이 이미 사용 중이면 기존 프로그램을 종료하거나 `PORT` 환경변수로 다른 포트를 지정할 수 있습니다.

# 네이버 쇼핑커넥트 블로그

상품을 먼저 내세우지 말고 독자의 문제와 해결 정보를 먼저 제공한다. 기본 결과물은 `정보글 90% + 마지막 상품 제안 10%` 구조로 작성한다.

## 핵심 원칙

- 독자가 검색으로 들어와 자신의 불편을 알아차리고, 원인과 해결 방법을 이해한 다음 필요한 제품 유형을 스스로 납득하게 한다.
- 제목과 본문에서 특정 브랜드명·상품명·모델명을 쓰지 않는다. 사용자가 제품 중심 리뷰나 비교를 명시적으로 요청한 경우에만 예외로 한다.
- 본문에서 가격·할인·쿠폰·배송·판매처·재고를 언급하지 않는다.
- `상세페이지에서 확인했다`, `공식몰에서 소개한다`처럼 조사 과정을 드러내지 않는다.
- 상품의 개별 장점을 본문에서 직접 홍보하지 않는다. 확인한 상품 특성은 독자가 제품군을 고를 때 필요한 일반적인 기능과 선택 기준으로 바꿔 설명한다.
- 상품은 글의 마지막 제안 문장과 링크에서만 연결한다. 본문 중간에는 상품 링크나 구매 버튼을 넣지 않는다.
- 직접 사용하지 않았다면 체험 후기처럼 쓰지 않는다.

## 실행 순서

1. 상품명, 용도, 형태, 옵션, 핵심 특징, 사용법, 주의 사항, 가격과 혜택을 내부 분석용으로 확인한다.
2. 제품이 해결할 수 있는 대표 불편 하나와 구매 가능성이 높은 핵심 독자 하나를 정한다.
3. 검색 유입용 핵심 키워드 하나와 보조 키워드 2~4개를 정한다.
4. 독자의 문제에서 시작해 생활 속 해결 방법과 제품군 선택 기준으로 이어지는 본문을 작성한다.
5. 마지막 1~2문장에서만 자연스럽게 상품을 제안하고, 글의 마지막 줄에 쇼핑커넥트 링크를 둔다.
6. 전체 문장을 소리 내어 읽는다고 가정하고 광고문·안내문·AI 문체를 제거한다.

로그인·권한·동적 페이지 문제로 상품 사실을 확인할 수 없으면 추정하지 말고 캡처나 상품 정보를 요청한다.

## 제목: 키워드 + 후킹

- 제목은 `핵심 검색 키워드 + 독자의 상황 또는 궁금증`으로 작성한다.
- 핵심 키워드는 가능한 한 제목 앞부분에 자연스럽게 한 번 넣는다.
- 후킹에는 독자가 실제로 겪는 불편, 놓치기 쉬운 원인, 선택 실수 또는 바로 얻을 해결 실마리를 넣는다.
- 후킹은 본문에서 실제로 답한다. 과장하거나 내용과 무관한 궁금증을 만들지 않는다.
- 상품명은 제목에 넣지 않는다. 사용자가 상품명 포함을 명시적으로 요청한 경우에만 넣는다.
- 키워드를 쉼표로 나열하거나 같은 뜻을 반복하지 않는다.

좋은 구조 예시:

- `발 편한 워킹화 고르는 법｜걸음이 조심스러워졌다면 보폭보다 이것부터`
- `좁은 주방 수납 정리법｜물건이 자꾸 쌓인다면 공간보다 먼저 볼 것`
- `민감성 피부 선크림 고르는 법｜바를 때마다 따갑다면 성분보다 먼저 확인할 부분`

피할 구조 예시:

- `추천 인기 가성비 필수템 BEST 상품명`
- `상품명 가격 후기 효과 총정리`
- `이 제품 무조건 써보세요`

## 본문 고정 구조

### 1. 광고 표시

글 최상단에 경제적 이해관계 표시 문구를 둔다. 광고 표시 다음에 상품명이나 스펙표를 붙이지 말고 바로 독자의 상황으로 들어간다.

### 2. 생활 속 문제 장면

- 독자가 자주 겪는 구체적인 순간으로 시작한다.
- `혹시 이런 적 있으신가요?` 같은 상투적인 질문보다 실제 행동과 느낌을 묘사한다.
- 첫 3~5문단 안에서 제목의 궁금증에 대한 방향을 제시한다.

### 3. 문제 인식과 원인

- 한 가지 원인으로 단정하지 않는다.
- 독자가 자신의 상태를 판단할 수 있는 관찰 기준을 편안한 말투로 설명한다.
- 의료·안전 관련 글은 위험 신호와 진료가 필요한 상황을 짧고 분명하게 넣되 공포를 과장하지 않는다.

### 4. 생활 속 해결 방법

- 오늘 바로 할 수 있는 행동부터 설명한다.
- 방법, 순서, 강도, 멈춰야 할 상황을 구체적으로 쓴다.
- 제품 없이 먼저 해볼 수 있는 점검과 개선 방법을 충분히 제공한다.

### 5. 제품군이 필요한 상황과 선택 기준

- 특정 상품을 연결하지 말고 `워킹화`, `수납함`, `선크림`처럼 제품군만 말한다.
- 상품의 확인된 특징을 일반적인 선택 기준으로 바꿔 설명한다.
- 기능을 나열하지 말고 그 기능이 어떤 불편과 관계있는지를 생활 장면 안에서 풀어쓴다.
- 긴 체크리스트보다 1~2문장짜리 짧은 문단을 이어서 설명한다.
- 독자가 자기 환경, 규격, 신체 조건, 호환성 또는 사용 습관에 맞는지 판단하게 한다.

### 6. 마무리와 상품 링크

- 본문 내용을 짧게 정리하고 독자가 먼저 해볼 행동을 다시 짚는다.
- 마지막 제안은 작가가 골라둔 선택지를 가볍게 건네는 말투로 쓴다.
- 마지막 링크의 앵커는 제품명을 반복하지 말고 용도 중심으로 쓴다.
- 링크 뒤에는 본문, 출처, 해시태그, 추가 안내를 붙이지 않는다. 링크가 글의 마지막 줄이어야 한다.

권장 마무리 예시:

> 이런 기준으로 사용할 제품을 찾고 있다면 제가 골라둔 선택지도 아래에서 한번 살펴보세요. 내게 맞는 크기와 옵션이 있는지 본 뒤 천천히 결정하시면 됩니다.
>
> **[용도에 맞는 제품 살펴보기 — 쇼핑커넥트 링크]**

## 문체

- 경험 많은 작가가 옆에서 정보를 설명하듯 편안한 구어체로 쓴다.
- 한국어 기준 1,300자 이상을 기본으로 하되 같은 설명을 반복해 분량을 채우지 않는다.
- 한 문단은 1~2문장으로 제한하고 의미 단위로 줄바꿈한다.
- 문장 끝을 `~해요`, `~입니다`, `~죠`, `~거든요` 등으로 자연스럽게 섞는다.
- `확인해 보세요`, `살펴보세요`, `비교해 볼 수 있습니다`, `도움이 됩니다`를 반복하지 않는다.
- `치료제가 아니라`, `화려한 광고 문구보다`, `구매 전 체크`, `이런 분께 추천`, `한눈에 보는 스펙` 같은 정형화된 광고·AI 표현을 기본 본문에 쓰지 않는다.
- `중요합니다`, `필요합니다`만 반복하지 말고 왜 그런지 생활 언어로 설명한다.
- 독자에게 훈계하거나 구매를 재촉하지 않는다.
- 확인하지 않은 효능, 성능, 수치, 비교 우위는 만들지 않는다.

## 상품 분석과 사실 사용

- 상품 페이지의 사실은 내부 판단과 선택 기준 작성에 사용한다.
- 제품의 소재, 규격, 호환성, 조절 방식처럼 독자의 선택에 필요한 사실만 일반 기준으로 전환한다.
- 상품에 없는 기능을 제품군의 일반적인 특징이라는 이유로 덧붙이지 않는다.
- 리뷰는 반복되는 사용 불편을 파악하는 참고 자료로만 사용한다. 리뷰를 성능 근거처럼 단정하지 않는다.
- 사용자가 원하면 본문 밖 별도 메모로 상품 분석, 가격, 옵션, 링크 상태를 제공한다. 이를 기본 본문에 섞지 않는다.

## 해시태그

- 핵심 키워드, 문제 상황, 제품군을 조합해 5~10개를 만든다.
- 해시태그는 게시 설정용 별도 항목으로 제공하고 본문 마지막 링크 뒤에는 붙이지 않는다.

## 이미지 규칙

- 대표 1장, 문제 상황 1~2장, 해결 행동 1~2장, 제품 디테일 1~2장을 기본으로 구성한다.
- 상세페이지 원본은 로고만 있는 컷, 이벤트 배너, 후기 캡처, 중복 이미지를 제외한다.
- AI 연출 이미지는 문제 상황과 사용 공간을 설명하는 용도로 만든다.
- AI 이미지에 상품이 보이면 실제 상품 이미지를 참조하고 형태, 색상, 로고, 구성, 비율과 질감을 동일하게 유지한다.
- 실제 제품을 정확히 유지할 수 없으면 제품 없는 생활 장면으로 바꾼다.
- AI 이미지는 실제 성능이나 구성의 근거로 사용하지 않고 `AI 연출 이미지`로 표시한다.

## 기본 출력 순서

1. 핵심 독자와 검색 키워드
2. 최종 제목 1개와 제목 대안 3개
3. 광고 표시 문구
4. 소제목이 있는 완성 본문
5. 게시 설정용 해시태그 5~10개
6. 이미지 배치와 원본·AI 이미지 목록
7. 이미지 미리보기와 ZIP 링크
8. 본문 마지막에 넣을 쇼핑커넥트 링크 문구

사용자가 글만 요청하면 1~5와 링크 문구만 제공하고 이미지 수집·생성·ZIP은 생략한다.

## 완료 점검

- 제목 앞부분에 핵심 키워드가 자연스럽게 들어갔는가?
- 제목의 후킹을 본문에서 실제로 해결했는가?
- 본문과 소제목에 특정 상품명, 브랜드명, 모델명, 가격이 없는가?
- 상세페이지나 공식몰을 확인했다는 작업 과정이 노출되지 않았는가?
- 독자의 문제, 원인, 해결 행동, 제품군 선택 기준 순서가 자연스러운가?
- 기능 나열과 체크리스트 대신 생활 언어로 설명했는가?
- 직접 사용하지 않은 경험을 후기처럼 꾸미지 않았는가?
- 광고·AI 문체와 반복 표현을 제거했는가?
- 상품 제안과 링크가 글의 마지막에만 있는가?
- 링크 뒤에 다른 내용이 붙지 않았는가?

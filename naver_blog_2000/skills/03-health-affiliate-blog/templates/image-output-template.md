# 이미지 생성·저장 결과 형식

글의 1차 임시저장이 확인되면 대표이미지 1장과 이미지 자리 수에 맞는 본문 이미지 4~6장을 생성한다. 생성 전이나 폴더 저장 전에는 이 결과를 완료로 사용하지 않는다.

```text
글 제목: [제목]
저장 폴더: %USERPROFILE%\Downloads\건강블로그이미지\YYYY-MM-DD-글제목

00-대표이미지-[핵심키워드].png — 1080×1080px, 1:1 / 핵심 키워드: [키워드] / 관련 문구: [짧은 문구]
01-[장면].png — 본문 이미지 자리 1: [caption]
02-[장면].png — 본문 이미지 자리 2: [caption]
03-[장면].png — 본문 이미지 자리 3: [caption]
04-[장면].png — 본문 이미지 자리 4: [caption]
05-[장면].png — 본문 이미지 자리 5: [caption] (선택)
06-[장면].png — 본문 이미지 자리 6: [caption] (선택)

로컬 검증: 대표이미지 1장 + 본문 이미지 [N]장, 전체 [N+1]장 저장 확인
네이버 배치: 같은 제목의 1차 임시글 갱신 / 대표이미지 맨 위 + 본문 이미지 [N]장 slot 순서 배치
2차 검증: 전체 [N+1]장 확인 / 이미지 자리·추천 장면 문구 없음 / 2차 임시저장 확인
```

- 대표이미지는 1080×1080px 정사각형으로 저장하고 확정한 핵심 키워드와 관련 문구만 정확히 넣는다.
- 본문 이미지에는 텍스트·로고·워터마크·브랜드·읽을 수 있는 제품 표시를 넣지 않는다.
- 자동 배치는 위 파일 순서대로 진행하고, 해당 이미지 자리 안내 문구를 지운 뒤 같은 임시글에 2차 임시저장한다.

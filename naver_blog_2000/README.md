# 네이버 건강블로그자동화 · 2000

3000 티스토리 사이트와 같은 화면과 작업 흐름을 네이버 블로그에 적용한 별도 로컬 사이트입니다. 기존 3000·8000 사이트의 코드, 로그인 세션, 작업 이력은 변경하거나 공유하지 않습니다.

관심분야 키워드를 입력하면 **글감 수집 → AI 글 작성 → 대표이미지 1장과 본문 이미지 4~6장 생성 → 네이버 1차 임시저장 → 같은 글에 이미지 배치 → 2차 임시저장 또는 발행**까지 진행합니다. 브랜드커넥트 상품이 연결된 경우 네이버 에디터의 쇼핑커넥트 카드와 제휴 고지 규칙을 따릅니다.

## 필요 조건

- Node.js 18+
- Codex CLI에서 ChatGPT 로그인 상태 (`codex login status` 결과가 `Logged in using ChatGPT`) — AI 호출은 `codex exec`로 **ChatGPT/Codex 구독 요금제**를 사용합니다. OpenAI API 키와 API 종량제는 사용하지 않습니다.

## 실행

```bash
npm install
npm start
```

또는 `start-naver-blog-2000.cmd`를 더블클릭합니다.

브라우저에서 `http://localhost:2000` 접속.
첫 실행 시 Playwright Chromium이 없으면 자동으로 설치합니다.

## 다른 컴퓨터에서 설치

PowerShell 또는 명령 프롬프트에서 아래 명령을 순서대로 실행합니다.

```bash
git clone --branch codex/naver-health-auto-publish-2000 --single-branch https://github.com/coco7899/blog_fashion_custom.git
cd blog_fashion_custom/naver_blog_2000
npm install
```

설치가 끝나면 `start-naver-blog-2000.cmd`를 더블클릭하고 `http://localhost:2000`을 엽니다.

- 새 컴퓨터에도 Node.js 18 이상과 Codex CLI가 필요합니다.
- `codex login`으로 ChatGPT 계정에 로그인해야 AI 글쓰기가 작동합니다.
- 네이버 로그인은 새 컴퓨터에서 한 번 직접 진행해야 합니다.
- 네이버 로그인 정보, 작업 이력, 생성 이미지와 로그 파일은 GitHub에 포함되지 않습니다.

작업 이력과 로그인 세션은 저장소 밖의 `../naver_blog_2000_data` 폴더에 별도로 저장됩니다. 저장 위치를 변경하려면 `NAVER_BLOG_2000_DATA_DIR` 환경변수를 사용합니다.

## 사용 흐름

1. **네이버 로그인** — 우측 상단 로그인 버튼 → 브라우저 창이 뜨면 직접 로그인합니다. 세션은 `../naver_blog_2000_data/session/naver-state.json`에 저장되어 재사용되며 아이디와 비밀번호는 코드에 저장하지 않습니다.
2. **키워드 입력 → 글감 찾기** — 네이버 뉴스·인기 블로그 글을 수집하고 AI가 글감 5개를 추천.
3. **글감 선택** — 참고자료 수집 → AI 글 작성 → 1차 임시저장 → 대표·본문 이미지 생성 → 같은 네이버 임시글에 이미지 배치 → 선택한 모드에 따라 2차 임시저장 또는 발행으로 진행합니다.
4. **발행 이력** — 완료된 글 링크와 읽기 전용 미리보기 제공.
5. **🎬 숏폼 만들기** — 작업 이력의 원고에서 세로 영상(9:16)을 뽑습니다. 아래 참고.

처음에는 `임시저장`으로 결과를 확인한 뒤 `바로 발행`을 사용하는 것을 권장합니다.

## 숏폼 생성기

작업 이력에서 **🎬 숏폼** 버튼 → `shortform.html?id=<초안ID>` 편집기가 열립니다.

**흐름**: 블로그 원고 → AI 대본(후킹 + 장면별 자막·내레이션) → 장면 배경 이미지 배정 → 캔버스 미리보기/편집 → 영상 다운로드

**화면 구성** (1080 × 1920)

- 상단: 짧은 후킹 한 줄이 영상 내내 고정 노출 (기본 16자 이내)
- 화면 정가운데에서 **+10px 아래**부터 장면별 대본 자막 (슬라이더로 -300 ~ +500px 조정)
- 배경: 사진 1장이 천천히 확대(켄번즈) + 하단 장면 진행 바

**배경 이미지 소스**

- `원고 사진 우선` — 블로그에 실제로 쓴(AI 워터마크·저작권 판정을 통과한) 사진을 순서대로 쓰고, 모자란 장면만 AI로 생성
- `전부 AI 생성` — 모든 장면을 Pollinations로 새로 생성 (인물·상표 없는 분위기 컷, 저작권 안전). 장면당 20~40초 소요

**영상 인코딩은 브라우저에서** — 이 PC에 ffmpeg가 없어도 되도록, `canvas.captureStream()` + `MediaRecorder`로 렌더링합니다. 그래서:

- Chrome/Edge에서 열어야 하고, **녹화 중에는 탭을 다른 창으로 가리면 안 됩니다** (rAF가 멈춰 프레임이 끊깁니다)
- 브라우저가 mp4를 지원하면 mp4로, 아니면 webm으로 저장됩니다. webm은 인스타/틱톡 업로드 전 mp4 변환이 필요할 수 있습니다
- **소리는 들어가지 않습니다.** 장면별 `내레이션` 텍스트를 TXT로 받아 편집 앱에서 음악·더빙을 얹으세요

**저장 파일**: `data/drafts/<id>/shortform/shortform.json` (대본·스타일), 같은 폴더에 AI 배경 이미지

## 주의

- 네이버 에디터 UI가 변경되면 저장·발행 자동화가 실패할 수 있습니다. 실패 시 `../naver_blog_2000_data/drafts/<id>/publish-error.png`를 확인합니다.
- 건강정보는 진단이나 치료를 대신하지 않으며, 글과 이미지·제휴상품은 발행 전에 직접 확인하는 것을 권장합니다.

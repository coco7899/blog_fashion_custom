# 이미지 생성·전달 안내

이미지는 네이버 글에 자동으로 다시 넣지 않는다. 1차 임시저장이 확인된 뒤에만 생성한다.

저장 위치:

`C:\Users\이승아\Downloads\건강블로그이미지\YYYY-MM-DD-글제목\`

파일명은 본문 이미지 자리 순서와 같게 `01-대표장면.png`부터 매긴다. 최소 4장, 최대 6장으로 만든다.

각 이미지에는 텍스트·로고·워터마크·제품 포장·약 이름을 넣지 않는다. 자연스러운 생활 장면을 사용하고, 같은 구도를 반복하지 않는다.

완료 보고에는 다음을 포함한다.

- 글 제목
- 이미지 폴더 경로
- 파일별 장면과 넣을 본문 위치
- 사용자가 네이버에서 사진을 직접 넣은 뒤 이미지 자리 안내 문구를 지우면 된다는 한 줄 안내

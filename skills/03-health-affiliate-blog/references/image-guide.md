# 이미지 생성·전달 안내

이미지는 1차 비공개 저장이 확인된 뒤에만 생성한다. 로컬 저장과 파일 검증이 끝나면 같은 티스토리 글을 다시 열어 자동 배치하고 최종 저장 또는 발행한다.

저장 위치:

`C:\Users\이승아\Downloads\건강블로그이미지\YYYY-MM-DD-글제목\`

대표이미지 1장과 본문 이미지 4~6장을 만든다. 대표이미지는 `00-대표이미지-핵심키워드.png`, 본문 이미지는 자리 순서와 같게 `01-본문장면.png`부터 매긴다. 전체 파일 수는 5~7장이다.

대표이미지는 항상 `1080×1080px`, 화면 비율 `1:1`의 정사각형으로 만든다. 핵심 키워드 1개와 관련 문구 1개만 넣는다. 관련 문구는 글의 독자가 얻을 내용을 8~18자 정도로 요약하고 과장·공포·치료 보장·구매 유도 표현을 피한다. 먼저 문구 여백이 있는 정사각형 배경을 생성한 뒤 로컬 편집으로 정확한 한글 문구를 입힌다.

본문 이미지에는 텍스트·로고·워터마크·제품 포장·약 이름을 넣지 않는다. 자연스러운 생활 장면을 사용하고, 같은 구도를 반복하지 않는다.

배치할 때 대표이미지는 글 맨 위에 넣고, 본문 이미지는 `01`부터 원고의 이미지 자리 `slot` 순서대로 넣는다. 기존 `이미지 N 넣을 자리`와 `추천 장면:` 문구는 남기지 않는다. 저장된 티스토리 글의 제목이 정확히 일치하는 경우에만 기존 본문을 다시 구성하며, 제목이 다르면 아무 내용도 지우지 않는다.

최종 저장 뒤에는 같은 글을 다시 열어 전체 이미지 수가 로컬 파일 수와 같은지, 자리 안내 문구가 사라졌는지 확인한다. 실패하면 1차 비공개 글과 로컬 파일을 보존하고 배치 단계만 재시도한다.

완료 보고에는 다음을 포함한다.

- 글 제목
- 이미지 폴더 경로
- 대표이미지의 핵심 키워드와 관련 문구
- 파일별 장면과 넣을 본문 위치
- 티스토리에 실제 배치한 이미지 수
- 최종 저장 또는 발행 재확인 결과

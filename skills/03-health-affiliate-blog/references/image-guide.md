# 이미지 자리 가이드

Codex가 글감 선택부터 직접 처리한 경우, 네이버 임시저장 완료를 확인한 뒤 이 가이드에 따라 이미지 4~6장을 생성해 다운로드 폴더에 저장한다. 이어서 같은 네이버 임시글을 다시 열어 이미지 자리 순서대로 업로드하고 재임시저장한다. ZIP 파일은 만들지 않는다.

저장 위치:

`C:\Users\이승아\Downloads\건강블로그이미지\YYYY-MM-DD-글제목`

파일명은 이미지 자리 순서대로 `01-대표-장면.png`부터 지정한다. 네이버에서는 같은 순서의 이미지 자리를 찾아 한 장씩 교체한다. 이미지 업로드가 끝난 뒤에는 미리보기와 임시저장 성공 신호를 확인한다.

본문에는 4~6개의 이미지 자리도 함께 만든다.

각 자리에는 `slot`, 짧은 `caption`, 구체적인 `desc`를 넣는다.

필수 역할:

1. 대표 장면
2. 독자의 문제 상황
3. 식재료 또는 생활 도구
4. 실천 장면

필요하면 서로 다른 추가 장면 1~2개를 더한다.

- 자연스러운 생활 장면으로 설명한다.
- 비슷한 구도를 반복하지 않는다.
- 텍스트·로고·브랜드 제품이 보이지 않게 설명한다.
- 대표 장면은 16:9 또는 1:1, 나머지는 4:5 또는 1:1을 권장한다.

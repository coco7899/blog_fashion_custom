# 이미지 자리 가이드

이미지를 생성·다운로드·ZIP 저장하지 않는다. 본문에는 4~6개의 이미지 자리만 만든다.

각 자리에는 `slot`, 짧은 `caption`, 구체적인 `desc`를 넣는다.

필수 역할:

1. 대표 장면
2. 독자의 문제 상황
3. 식재료 또는 생활 도구
4. 실천 장면

필요하면 서로 다른 추가 장면 1~2개를 더한다.

- 자연스러운 생활 장면으로 설명한다.
- 비슷한 구도를 반복하지 않는다.
- 텍스트·로고·브랜드 제품이 보이지 않게 설명한다.
- 대표 장면은 16:9 또는 1:1, 나머지는 4:5 또는 1:1을 권장한다.

# 건강 정보 글 출력 템플릿

이 템플릿은 건강 글의 기본 순서다. 제목에서 숫자를 약속했다면 서론 뒤 핵심 요약과 본문의 판단 기준도 반드시 같은 숫자로 맞춘다.

티스토리 저장 시 아래 `##` 소제목은 모두 인용구 스타일로 입력한다.
아래 이미지 자리와 추천 장면 문구는 1차 비공개 저장에서만 사용한다. 이미지 생성 뒤 같은 글을 다시 열어 해당 문구를 삭제하고, 대표이미지는 글 맨 위에, 본문 이미지는 각 자리 순서에 배치한 뒤 최종 저장 또는 발행한다.

[이어지는 문단: 질문에 자연스럽게 직접 답하고 단정할 수 없는 이유를 짧게 설명한다. `먼저 답하면`, `결론부터 말하면`으로 시작하지 않는다.]

[서론 마지막 문장: 언제 심한지, 무엇과 함께 나타나는지, 평소와 무엇이 다른지처럼 이 글에서 확인할 범위를 안내한다. 서론 전체는 2~4문단으로 끝낸다.]

# 이미지 생성·저장 결과 형식

글의 1차 임시저장이 확인되면 이미지 자리 수에 맞춰 4~6장을 생성한다. 생성 전이나 폴더 저장 전에는 이 결과를 완료로 사용하지 않는다.

```text
글 제목: [제목]
저장 폴더: C:\Users\이승아\Downloads\건강블로그이미지\YYYY-MM-DD-글제목

01-[장면].png — 본문 이미지 자리 1: [caption]
02-[장면].png — 본문 이미지 자리 2: [caption]
03-[장면].png — 본문 이미지 자리 3: [caption]
04-[장면].png — 본문 이미지 자리 4: [caption]
05-[장면].png — 본문 이미지 자리 5: [caption] (선택)
06-[장면].png — 본문 이미지 자리 6: [caption] (선택)

검증: PNG/JPG/WebP [N]장 저장 확인
```

- 이미지에는 텍스트·로고·워터마크·브랜드·읽을 수 있는 제품 표시를 넣지 않는다.
- 사용자가 네이버 임시글에 직접 사진을 넣을 때는 위 파일 순서대로 넣고, 해당 이미지 자리 안내 문구를 지운다.

# 03-health-affiliate-blog

## 목표

생활 속 한 가지 건강 문제를 근거와 실천 방법으로 풀어 쓴다. 독자가 불안을 느껴 약을 임의로 사거나 바꾸게 만들지 않고, 오늘 점검할 행동과 안전한 선택 기준을 알게 한다.

## 자료 조사

1. 키워드 또는 최근 건강 뉴스에서 생활 문제 하나를 고른다.
2. 정부·공공기관, 대학병원, 전문학회, 원 연구자료를 우선하고 신뢰할 수 있는 언론 기사를 보완 자료로 쓴다.
3. 기사 날짜와 발표 기관을 확인한다. 출처가 부족하면 공식 자료를 추가한다.
4. 기사 문장을 복사하지 말고, 사실·한계·개인차를 쉬운 한국어로 풀어 쓴다.

## 건강 안전 원칙

- 질병 치료·예방·수치 개선을 단정하지 않는다.
- 처방약, 일반의약품, 약 복용·중단·용량 변경을 제휴 추천하거나 유도하지 않는다.
- 증상만으로 진단하지 않는다. 통증·고열·호흡곤란·실신·의식 변화·혈뇨 등 긴급 신호가 주제와 관련되면 진료 또는 응급 도움 필요성을 분명히 쓴다.
- 수분·식사·운동 제한은 심장·콩팥 질환, 임신, 복용 약, 의료진 지시에 따라 달라질 수 있음을 안내한다.
- 직접 사용하지 않은 제품은 체험 후기처럼 쓰지 않는다.

## 원고 구성

- 글을 시작하기 전에 검색자가 가장 궁금해할 핵심 질문을 1개만 정한다. 서로 다른 건강 질문을 한 글에 섞지 않는다.
- 제목은 기본적으로 `핵심 키워드 + 자연스러운 질문 + 답변 범위`로 쓴다. 예: `질염이 의심될 때 질 세정제를 써도 될까요? 피해야 할 관리법`.
- 홈판형·감성형 문구는 기본 제목이 아니라 필요할 때 대표 이미지 문구나 도입 후킹에만 쓴다.
- 첫 일반 문단의 첫 2~4문장 안에 핵심 질문의 직접 답을 먼저 쓰고, 이어서 근거·예외·글에서 확인할 기준을 설명한다.
- 소제목은 5~7개 중 적어도 3개를 질문형으로 쓴다. 질문형 소제목 바로 아래 첫 문장에는 직접 답을 두고 이유·근거·예외·실천 방법을 잇는다.
- 건강 수치·효능·권장량·질병 정보는 공공기관, 전문학회, 의료기관, 원 연구자료로 확인한다. 신문·블로그 자료는 보완용으로만 쓰며 출처 밖의 내용은 추측하지 않는다.
- 수치에는 기준 단위(1회 제공량, 100g, 1개 등), 최신성이 중요한 정보에는 발표 기관과 자료 기준 날짜를 함께 쓴다.
- 첫 3문단 안에 하나의 구체적인 생활 장면을 넣는다.
- 소제목은 5~7개, 인용구는 최대 1개, 해시태그는 정확히 6개로 쓴다.
- 본문은 보통 1,500~2,200자, 문단은 1~3문장으로 쓴다.
- 비용 없이 먼저 할 수 있는 실천, 선택 기준, 주의가 필요한 사람을 모두 넣는다.
- 글 후반에는 핵심 답을 2~3문장으로 다시 정리하고, 오늘 바로 할 행동을 제시한다.
- 같은 효능·구매 이유를 반복하지 않는다.

## 실행 순서

Codex가 글감 선택부터 직접 처리하는 작업은 아래 순서를 기본값으로 끝까지 수행한다. 사용자가 이미지를 따로 요청하지 않아도 4~6단계를 생략하지 않는다. **1차 임시저장은 중간 단계일 뿐 완료가 아니다.** 6단계의 2차 임시저장까지 확인한 경우에만 사용자에게 작업 완료라고 알린다.

여러 글감을 요청받아도 병렬로 1차 임시저장하지 않는다. **한 글의 제목·본문·이미지 자리를 기억하는 같은 작업 흐름 안에서** `1차 임시저장 → 이미지 생성·로컬 저장 → 같은 글 재열기·배치 → 2차 임시저장`을 모두 끝낸 뒤, 다음 글감으로 넘어간다.

1. 건강 글감 1개를 선택하고 근거를 조사한다.
2. 검색 질문형 건강 글을 작성하고 네이버에는 발행하지 않고 임시저장한다.
3. 1차 임시저장 완료 상태와 글 제목, 이미지 자리 수를 확인한다. 이때는 `이미지 작업 대기` 상태로 보고한다.
4. 각 이미지 자리에 맞는 이미지 4~6장을 생성하고 `C:\Users\이승아\Downloads\건강블로그이미지\YYYY-MM-DD-글제목` 폴더에 저장한다.
5. 같은 네이버 임시글을 다시 열어 이미지 자리 순서대로 이미지 1장씩 업로드한다. 각 업로드 뒤 해당 자리의 `🖼 이미지 N 넣을 자리`와 `추천 장면: ...` 안내 문구를 모두 삭제한다. 어떤 이미지 자리에도 안내 문구가 남지 않았는지 확인한다.
6. 이미지가 모두 보이고, 이미지 자리·추천 장면 안내 문구가 하나도 남지 않았는지 확인한 뒤 같은 글을 다시 임시저장한다. 발행은 하지 않는다.
7. 파일명은 이미지 자리 순서대로 `01-대표-장면.png`부터 지정하고, 생성한 이미지 수·저장 폴더·2차 임시저장 여부를 사용자에게 알린다.

이미지는 텍스트·로고·브랜드 제품·의약품·의료적 진단 장면 없이 자연스러운 생활 장면으로 만든다. 네이버 편집 과정에서 이미지 업로드 또는 재임시저장에 실패하면 실패 사실과 어느 이미지 자리까지 반영됐는지를 알리고, 발행하지 않는다.

## 이미지 자리와 생성 기준

본문에는 4~6개의 `image` 블록을 배치하고 각 블록에 다음을 쓴다.

- `slot`: 1부터 순서대로
- `caption`: 본문에서 보일 짧은 이미지 자리 제목
- `desc`: 나중에 이미지를 만들거나 고를 수 있을 만큼 구체적인 추천 장면

역할은 대표 장면, 독자의 문제 상황, 식재료·생활 도구, 실천 장면을 겹치지 않게 구성한다. 이미지 자리에는 텍스트·로고·브랜드 제품이 없는 자연스러운 생활 장면을 설명한다. ZIP 파일은 만들지 않는다.

## 제휴 추천 제품

글마다 마지막 CTA에 글과 직접 연결되는 **비처방 제품 1개**만 추천한다. 자동으로 제휴 링크·가격·할인·후기·구매 고지는 넣지 않는다.

추천 가능한 예:

- 식재료, 생활용품, 기록 노트, 눈금 물병, 가정용 측정 도구

추천 불가:

- 처방약·일반의약품, 치료 목적 제품, 효과를 보장해야만 연결되는 제품

제품은 `이 글에 제휴하면 좋은 제품 후보: **제품명**` 형식으로 쓰고, 사용자가 제휴 여부를 직접 판단할 후보임을 밝힌다. 생활 실천에 쓰이는 이유와 한계를 한 문장으로 덧붙인다. 측정 도구는 진단·처방을 대신하지 않는다고 명시한다.

## 마지막 배치 순서

네이버 임시저장과 사이트 미리보기 모두 아래 순서를 지킨다.

```text
본문과 이미지 자리


마지막 CTA와 제휴 추천 제품 후보
해시태그 6개 (글 전체 맨 아래)
```

출처 제목·URL·출처 목록은 본문과 이미지 캡션에 넣지 않는다. 조사에 사용한 자료는 내부 기록으로만 남긴다. 사용자가 제휴 링크를 직접 추가할 때는 추천 제품 문단에 직접 추가하고, 의료·약물 관련 링크는 넣지 않는다.

## 마지막 CTA

마지막 CTA는 `반복되는 생활 문제 → 오늘 점검·기록·준비할 행동 → 나에게 필요한 선택` 순서로 2~3문장으로 쓴다. 이 문단은 바로 앞 본문과 빈 줄 두 줄을 두어 분리한다. 구매를 강요하지 않는다.

좋은 예:

> 더운 날 물을 몰아 마시는 습관이 반복된다면 오늘부터 마신 시간과 야외 활동을 함께 기록해 보세요. 이 글에 제휴하면 좋은 제품 후보: **눈금 있는 휴대용 물병**. 수분 섭취를 나누어 기록하는 생활 도구이며, 진단·치료나 의료진의 개인별 수분 제한 안내를 대신하지는 않습니다.

## 최종 검수

1. 근거와 출처가 충분한가?
2. 건강 불안·치료 약속·약물 구매 유도가 없는가?
3. 이미지 자리가 4~6개이고 각 장면이 구체적인가?
4. 해시태그가 정확히 6개인가?
5. 제목이 핵심 키워드를 포함한 검색 질문형이며, 첫 문단에서 그 질문에 직접 답하는가?
6. 질문형 소제목이 3개 이상이고, 각 질문 구간이 답 → 근거 → 예외 → 실천 흐름인가?
7. 마지막 CTA에 행동 제안과 비처방 제품 후보 1개가 있는가?
8. 출처가 본문·이미지 캡션에 없고, 네이버 저장 순서가 `본문 → 빈 줄 두 줄 → CTA·추천 → 해시태그`인가?
9. 네이버 임시저장이 확인된 뒤 이미지 자리 수만큼 4~6장을 생성해 글별 다운로드 폴더에 저장했는가?
10. 같은 임시글에 이미지가 자리 순서대로 배치됐고, 이미지 반영 후 재임시저장이 확인됐는가?

# 네이버 쇼핑커넥트 블로그

상세페이지에서 확인한 사실만 바탕으로 모바일에서 읽기 쉬운 네이버 블로그 글을 만든다.

## 실행 순서

1. 상품명, 구성·옵션, 핵심 특징, 사용 방법과 주의 사항을 확인한다.
2. 가장 전환 가능성이 높은 핵심 독자 또는 사용 공간을 하나 정한다.
3. 상세페이지 원본 이미지 중 대표·구성·사용 장면을 보여주는 1~5장을 선별한다.
4. 생활밀착형 문제 해결 글을 작성하고, 필요한 경우 이미지 미리보기와 ZIP을 함께 제공한다.

로그인·권한·동적 페이지 문제로 정보를 확인할 수 없으면 추정하지 말고 캡처나 상품 정보를 요청한다.

## 글쓰기 기준

- 기본값은 생활밀착형 문제 해결 글이다. 상품 설명보다 먼저 독자의 불편·헷갈림·망설임이 드러나는 실제 생활 장면으로 시작한다.
- “이런 거 필요하신 분들 계시죠?”, “정품과 호환품 사이에서 헷갈리는 분들 많으시죠?”, “저만 어려웠던 거 아니죠?”처럼 독자가 자기 이야기라고 느낄 만한 질문을 문맥에 맞게 사용한다.
- 한 글에서 타깃을 과도하게 넓히지 않는다. 예를 들어 업소용 제품은 카페·식당·운동시설 등 주 사용 공간 하나를 중심으로 쓴다.
- 제목은 `독자가 겪는 문제 + 해결 실마리 + 상품명` 흐름으로 작성한다. 최종 제목 1개와 제목 대안 3개를 제공한다.
- 직접 사용하지 않았으면 후기처럼 꾸미지 않는다. 그렇다고 “직접 사용한 후기가 아니라”, “확인된 자료를 토대로”처럼 작성 방식을 해명하지도 않는다.
- 본문은 한국어 기준 1,200~1,600자로 작성한다.
- 한 문단은 1~3문장으로 자연스럽게 이어 쓰고 의미 단위로 줄바꿈한다. 같은 어미를 연달아 반복하지 않는다.
- 상세페이지 문구를 복사하지 말고 새 문장으로 쓴다. 확인하지 않은 효능·성능·수치·비교를 만들지 않는다.
- “상세페이지에는”, “안내됩니다”, “표시됩니다”, “소개됩니다”, “기재되어 있습니다”처럼 판매 화면을 해설하는 표현을 쓰지 않는다.
- “선택 이유가 될 수 있어요”, “생활 패턴에 어울려요”, “참고하는 자료일 뿐”, “작성 시점 기준으로 확인된 판매가는”처럼 AI 보고서로 들리는 표현을 쓰지 않는다.
- 리뷰·평점·재구매 수·구매자 반응을 본문에서 요약하지 않는다. “후기 중에는”, “구매자는”, “자주 묻는 질문”, “질문에는”, “의견도 있었어요” 같은 리뷰·Q&A 형식을 사용하지 않는다.
- 리뷰에서 발견한 주의점은 경험담으로 인용하지 말고 “이럴 수도 있으니 처음 사용할 때 이 부분을 확인해 주세요”처럼 가능성과 확인 방법으로만 짧게 바꾼다.
- 상품의 구성·수량·호환 모델·형태·선택 옵션·사용 방법처럼 공식 상품 자료에서 확인되는 특징을 중심으로 풀어 쓴다.
- 가격, 판매가, 할인가, 할인율, 쿠폰, 적립, 배송비, 수수료처럼 금액과 혜택에 관한 내용은 제목·본문·요약·캡션에 넣지 않는다.
- 공정위 문구, 광고·제휴·경제적 이해관계 표시 문구를 포스팅에 넣지 않는다.
- `출처`, `공식 스토어`, 상세페이지 주소, 이미지 출처 같은 출처 표기와 출처 목록을 포스팅에 넣지 않는다. 글 마지막의 쇼핑커넥트 상품 구매 링크는 출처가 아니므로 유지한다.
- “~다고 해요”, “~더라고요”, “~하면 좋겠습니다”, “~봐주세요”, “~거든요”, “~죠”를 문맥에 맞게 섞어 친한 사람이 알아본 내용을 알려주는 말투로 쓴다.
- 구매 전 체크는 상품별로 쓴다. 대형 가전은 설치 폭·전원·동선, 생활용품은 규격·호환성, 화장품은 성분·사용법을 우선한다.

## 스펙 요약

대표 이미지와 공감형 도입 2~3문단 뒤에 3~4개 항목의 `핵심만 보기`를 넣는다.

- 상품명, 형태·사용 방식, 핵심 특징, 구성·호환 조건, 제조·원산지 중 확인된 정보만 사용한다.
- 표 대신 줄바꿈 중심의 짧은 형식을 사용한다.
- 핵심 요약에도 가격·혜택·광고 문구·출처를 넣지 않는다.

## 본문 구조

1. 대표 이미지 1장
2. 독자의 생활 고민과 마음을 헤아리는 도입 2~3문단
3. 구성·호환 조건·용도를 짧게 보여주는 `핵심만 보기`
4. 상품의 구성과 특징을 생활 속 의미와 연결한 본문
5. 필요한 사람을 다시 떠올려주고 상품 링크로 자연스럽게 이어지는 마무리

- 소제목은 꼭 필요한 짧은 구절만 2~4개 사용한다.
- 핵심 구성, 꼭 확인할 조건, 독자가 기억해야 할 선택 기준 가운데 1~3곳만 `**굵게**` 표시한다. 문장 전체를 계속 굵게 만들지 않는다.
- 핵심 요약과 내용이 전환되는 지점은 인용구를 3~4개 사용해 구분한다. 굵게·인용구를 같은 내용에 중복 적용하거나 장식처럼 남발하지 않는다.
- “정리하면 세 가지만 기억하세요”처럼 보고서식으로 요약하며 끝내지 않는다.
- 상품 특징을 말할 때마다 어떤 사람에게 왜 필요한지 함께 설명하되 같은 표현을 반복하지 않는다.

## 이미지 규칙

- 대표 1장과 구성·핵심 특징·사용 장면을 보여주는 원본을 합쳐 1~5장 선별한다. 이미지가 적합하지 않으면 수를 억지로 채우지 않는다.
- 로고만 있는 컷, 이벤트 배너, 후기 캡처, 과도한 텍스트 이미지, 중복 이미지는 제외한다.
- AI 연출 이미지는 사용자가 요청했거나 글의 문제 상황을 설명하는 데 꼭 필요할 때만 만든다.
- 상품이 AI 이미지에 보이면 상세페이지에서 수집한 실제 상품 이미지를 참조 이미지로 반드시 사용한다.
- 제품의 형태, 색상, 로고 위치, 구성, 비율, 질감, 화면·버튼 등 보이는 모든 요소를 원본과 동일하게 유지한다.
- 비슷한 다른 제품을 생성하거나 디자인·색상·구성·성능을 바꾸지 않는다. 정확히 유지할 수 없으면 제품 없는 분위기컷으로 바꾸거나 추가 제품 사진을 요청한다.
- AI 생성 후 실제 참조 이미지와 형태·색상·로고·구성·비율을 눈으로 대조한다. 하나라도 다르면 사용하지 않고 재생성한다.
- AI 이미지는 실제 상품 구성·크기·성능의 근거로 사용하지 않고, 본문과 목록에서 `AI 연출 이미지`로 명확히 표시한다.
- 최종 응답에서 실제 사용 이미지를 미리보기로 보여 준다.

## 출력 순서

1. 상품 분석 요약과 핵심 타깃
2. 최종 제목 1개와 제목 대안 3개
3. 공감형 도입 뒤에 배치한 `핵심만 보기`
4. 상품 구성과 특징을 생활 속 의미로 풀어 쓴 본문과 이미지 배치
5. 자연스러운 마무리와 상품 구매 링크 위치
6. 해시태그 5~10개
7. 사용 이미지 미리보기
8. 상세페이지 원본 3~6장과 AI 연출 이미지 2~3장을 함께 담은 ZIP 링크

## 완료 점검

- 상세페이지를 실제로 확인했는가?
- 핵심 독자와 사용 공간이 명확한가?
- 제목과 도입부가 독자의 실제 고민과 마음에서 시작하는가?
- 상세페이지·리뷰·구매자 질문을 해설하는 문장이 없는가?
- 상품 구성·수량·호환 조건·옵션·사용 방법을 중심으로 설명했는가?
- AI 보고서 말투가 아니라 사람이 옆에서 알려주는 자연스러운 대화체인가?
- 중요한 구성과 선택 기준 1~3곳이 굵게 표시되고, 내용 전환이 인용구로 읽기 쉽게 구분되는가?
- 가격·할인·쿠폰·적립·배송비·수수료 내용이 모두 빠졌는가?
- 공정위·광고·제휴·경제적 이해관계 표시 문구가 모두 빠졌는가?
- 이미지 캡션과 글 하단에 출처 표기나 출처 목록이 없는가?
- 스펙과 주의 사항이 사실과 일치하는가?
- 실제 상품을 AI 이미지에서 동일하게 유지했는가?
- 원본과 AI 이미지의 역할·삽입 위치가 구분되는가?
- 이미지 미리보기와 ZIP을 제공했는가?

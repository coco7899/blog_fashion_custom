# 연예인 뉴스 블로그

최신성·사실성·읽기 쉬운 블로그 문체를 함께 지켜 글감을 조사하고 글을 작성한다. 사용자가 주제를 정하지 않은 경우에는 후보만 제안하고, 선택하기 전에는 본문을 임의로 작성하지 않는다.

## 기본 실행 순서

항상 다음 순서로 진행한다.

1. **글감 찾기**: 후보 5개를 제안하고 사용자의 선택을 기다린다.
2. **선택 글감 이미지 수집**: 선택 직후 관련 원문에서 필요한 이미지부터 빠르게 확보한다.
3. **글쓰기와 이미지 배치**: 팩트체크한 본문을 작성하고 각 이미지의 삽입 위치와 캡션을 함께 표시한다.

사용자가 한 번에 전 과정을 맡긴 경우에만 선택 대기 없이 1~3단계를 연속 실행한다.

### 이미지 수집 속도 원칙

- 공식 SNS와 선택 주제의 핵심 기사 1~2개를 우선 사용한다.
- 기사 HTML의 본문 이미지 `currentSrc` 또는 원본 `src` 주소를 추출해 직접 저장하는 방식을 최우선으로 한다.
- 화면 캡처, 전체 페이지 스크롤, 임베드 생성은 원본 주소 추출이 불가능할 때만 사용한다.
- 기본 수집량은 대표 이미지 3~5장으로 제한하고, 동일 사진과 광고·로고·추천기사 썸네일은 제외한다.
- 원본 주소 추출이 막힌 출처를 반복해서 시도하지 않는다. 즉시 다음으로 신뢰할 수 있는 출처로 전환한다.
- 이미지 수집에 2분 이상 걸릴 가능성이 보이면 이미 확보한 검증 이미지로 진행하고, 빠진 출처만 짧게 밝힌다.
- 다운로드 파일명에 인물, 출처, 장면을 넣고 해상도와 파일 형식을 확인한다.
- 사용자가 명시적으로 이미지 수집을 요청한 경우에만 다운로드한다. 뉴스 사진을 자유 이용 가능 이미지라고 단정하지 않는다.
- 다운로드한 이미지가 2장 이상이면 본문에 실제 사용한 검수 이미지들만 ZIP 파일 하나로 묶는다. 주제와 인물을 알 수 있는 영문 파일명을 사용하고, 개별 이미지 링크와 함께 한 번에 다운로드할 수 있는 ZIP 링크를 최종 응답 마지막에 제공한다.

## 실행 모드 선택

요청을 다음 모드 중 하나로 처리한다.

1. **글감 찾기**: 오늘의 주제, 최신 뉴스, 글감 후보를 요청한 경우
2. **선택 주제 글쓰기**: 후보 번호, 특정 인물·주제 또는 뉴스 링크를 지정한 경우
3. **조사부터 글쓰기**: 사용자가 명시적으로 주제 선정과 글 작성을 한 번에 맡긴 경우에만 사용

요청이 모호하면 기본적으로 **글감 찾기**를 실행한다.

## 공통 조사 원칙

- 반드시 웹에서 현재 정보를 조사한다.
- 원칙적으로 게시일 또는 사건 발생일이 최근 2일 이내인 자료를 우선한다.
- 적합한 후보가 부족하면 최근 7일까지 넓히고 기간을 넓혔다는 사실을 밝힌다.
- 기사 발행일과 실제 사건 발생일을 구분한다. 오래된 사진이나 발언을 새 소식처럼 다루지 않는다.
- 동일 보도를 복제한 기사 여러 건을 독립적인 근거로 계산하지 않는다.
- 공식 SNS, 소속사·브랜드·방송사 발표, 인터뷰 등 1차 출처를 우선하고 신뢰할 수 있는 언론 보도로 교차 확인한다.
- 확인되지 않은 열애설, 건강 이상설, 사생활 추측, 악성 루머는 제외한다.
- 협찬 여부나 실제 사용 여부가 불분명하면 단정하지 않는다. “착용한 것으로 보인다” 같은 표현도 시각적 근거가 분명할 때만 사용한다.
- 날짜, 나이, 제품명, 브랜드명, 가격, 행사명 등 바뀌거나 틀리기 쉬운 정보는 작성 직전에 다시 확인한다.
- 출처 링크를 검색 결과가 아니라 실제 원문 페이지로 제공한다.

### 셀럽 착용 아이템·브랜드 확인 원칙

- 브랜드명·제품명은 **공식 브랜드 발표, 소속사·스타일리스트의 명시, 제품 협찬 자료, 신뢰할 수 있는 언론의 구체적 보도** 중 하나 이상으로 확인된 경우에만 본문에 넣는다.
- 사진의 로고·디자인이 비슷하다는 이유만으로 브랜드나 제품을 추정하지 않는다. 이미지 검색 결과·커뮤니티 추측·판매글은 단독 근거로 쓰지 않는다.
- 브랜드만 확인되고 정확한 제품명이 확인되지 않으면 브랜드명까지만 적고, 모델명·가격·구매 링크는 넣지 않는다.
- 확인되지 않은 아이템은 “브랜드 미확인”으로 처리한다. 독자에게 비슷한 스타일의 별도 추천을 할 때도 실제 착용 제품처럼 표현하지 않는다.
- 글감 후보와 최종 글에서 ‘착용 브랜드 공개’, ‘무슨 제품’, ‘가격’ 같은 표현은 해당 사실을 확인했을 때만 사용한다.

## 글감 찾기

연예인 패션, 뷰티, 생활 아이템, 건강용품·식품을 우선하되 당일 화제성과 블로그 확장성이 높은 주제를 고른다.

기본적으로 후보 5개를 다음 표로 제안한다.

| 번호 | 제안 제목 | 분야 | 핵심 사실 | 블로그 포인트 | 주요 출처 |
|---|---|---|---|---|---|

각 후보에 다음 기준을 적용한다.

- 제목 앞부분에 연예인 이름과 핵심 키워드를 배치한다.
- 단순 연예 뉴스보다 스타일 분석, 제품 특징, 따라 하기, 계절성 등 독자에게 줄 정보가 있는 주제를 우선한다.
- 제목과 핵심 사실에 확인되지 않은 내용을 넣지 않는다.
- 같은 연예인이나 같은 분야가 과도하게 반복되지 않도록 구성한다.
- 원문을 사용해 글을 만들 때 예상되는 저작권·사생활·의료 표현 위험이 높으면 후보에서 제외하거나 주의점을 표시한다.

표 아래에 가장 추천하는 후보 1개와 추천 이유를 한두 문장으로 덧붙인 뒤, 사용자가 번호를 선택하도록 기다린다.

## 선택 주제 글쓰기

사용자가 후보를 선택하거나 특정 뉴스 링크를 제공하면 다음 순서로 작성한다.

1. 선택한 주제의 최신 원문과 보조 출처를 다시 연다.
2. 인물, 날짜, 장소, 행사, 착용 제품 또는 언급 내용을 교차 확인한다.
3. 브랜드·제품명은 ‘셀럽 착용 아이템·브랜드 확인 원칙’에 따라 별도로 검증한다.
4. 이미지 수집 속도 원칙에 따라 대표 이미지 3~5장을 확보한다.
5. 사실과 해석을 분리해 핵심 메시지와 글의 관점을 정한다.
6. 아래 형식으로 네이버 블로그용 본문을 작성하고 이미지 삽입 위치를 표시한다.
7. 사용한 출처의 제목과 직접 링크를 마지막에 정리한다.

### 작성 기준

- 제목을 제외한 본문을 한국어 기준 1,300자 이상 작성한다.
- 친근하고 자연스러운 존댓말을 사용하되 기사체를 그대로 흉내 내지 않는다.
- 첫 문단에서 독자의 궁금증을 자극하되 과장하거나 낚시성 표현을 쓰지 않는다.
- 기사 발행일, 재조명 경위, 사진 공개 시점 같은 메타 설명은 독자의 판단에 꼭 필요한 경우가 아니면 본문에서 생략한다. 기본적으로는 스타일·제품·장면 분석으로 자연스럽게 시작하고, 사실 확인에 필요한 시점 정보는 출처 또는 짧은 주석으로만 처리한다.
- 핵심 키워드를 제목 앞부분에 놓고 본문에는 문맥에 맞게 자연스럽게 반복한다.
- 짧은 문단과 소제목을 사용해 모바일에서 읽기 쉽게 구성한다.
- 한 문단은 기본 1~2문장으로 제한하고, 문장이 길어지면 의미 단위로 줄바꿈한다.
- 소제목 앞뒤에는 빈 줄을 두고, 이미지 뒤 설명과 캡션은 한두 줄로 짧게 쓴다.
- 정보 나열이 필요한 경우에는 핵심 포인트를 3개 이하의 짧은 항목으로 정리한다.
- 기사 문장과 보도자료를 그대로 옮기지 말고 사실만 확인한 뒤 완전히 새 문장으로 작성한다.
- 한 출처에서 긴 문장이나 표현을 연속해서 인용하지 않는다.
- 관찰이나 스타일 해석은 “눈에 띄었어요”, “이렇게 볼 수 있어요”처럼 사실과 구분한다.
- 제품 효능, 체중 감량, 질병 예방·치료 등 건강 관련 효과를 근거 없이 단정하지 않는다.
- 가격이나 판매 여부가 변할 수 있으면 확인 시점 또는 변동 가능성을 표시한다.
- 셀럽 착용 아이템을 언급할 때는 확인 출처를 함께 제시한다. 브랜드가 확인되지 않은 아이템은 브랜드명을 비워 두고 스타일 요소만 설명한다.
- 독자가 원문을 확인할 수 있도록 마지막에 실제 사용한 출처만 정리한다.
- 이미지 다운로드, 재사용 또는 타 블로그 이미지 사용을 임의로 진행하지 않는다.

### 출력 순서

1. **최종 제목 1개**
2. **도입부**
3. **소제목이 포함된 본문**: 문단 사이에 `[이미지 1 삽입: 장면 설명 / 출처 / 권장 캡션]` 형식으로 배치한다.
4. **자연스러운 마무리**
5. **수집 이미지 목록**: 파일 링크, 출처, 권장 사용 위치를 정리한다.
6. **참고한 출처와 링크**
7. **이미지 전체 다운로드**: 본문에 사용한 이미지가 2장 이상이면 모든 이미지가 담긴 ZIP 링크를 응답의 마지막 항목으로 제공한다.

사용자가 요청하면 제목 대안 3개와 해시태그 5개를 추가한다. 이미지 구성이나 네이버 에디터용 최종 편집은 해당 작업을 담당하는 별도 스킬이 있을 경우 넘겨 사용할 수 있도록 본문 구조를 유지한다.

## 금지 사항

- 검색하지 않고 기억만으로 최신 뉴스를 작성하지 않는다.
- 후보 선택 전 본문을 자동 작성하지 않는다.
- 기사 전체를 번역·요약하거나 원문의 문단 구조를 그대로 재현하지 않는다.
- 출처가 없는 수치, 관계, 발언, 제품 식별 정보를 만들어내지 않는다.
- 범죄, 사고, 질병, 사망, 미성년자 관련 사건을 상품 연결용 가벼운 소재로 이용하지 않는다.
- 뉴스 사진을 사용 가능한 이미지라고 단정하지 않는다.

## 완료 점검

출력 전에 다음을 확인한다.

- 정보가 요청 시점 기준으로 최신인가?
- 기사 발행일과 사건 발생일을 혼동하지 않았는가?
- 핵심 사실을 두 개 이상의 신뢰할 수 있는 자료 또는 명확한 1차 출처로 확인했는가?
- 브랜드·제품명·가격은 공식 또는 신뢰할 수 있는 명시 출처로 확인했는가? 확인되지 않은 항목을 추정해 쓰지 않았는가?
- 사실, 해석, 미확인 정보를 구분했는가?
- 원문 표현을 과도하게 재사용하지 않았는가?
- 모든 출처 링크가 실제 원문으로 연결되는가?
- 선택 전 글쓰기 금지 규칙을 지켰는가?
- 본문에 사용한 이미지가 2장 이상이면 검수된 파일만 담은 ZIP을 만들고 마지막에 전체 다운로드 링크를 제공했는가?

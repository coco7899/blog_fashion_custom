# 11-health-shopping-connect-blog

## 목표

건강정보만으로도 읽을 가치와 문제 해결이 충분한 글을 먼저 완성한다. 독자가 생활 속 불편을 이해한 뒤 제품이 실제 실천을 돕는 경우에만 치료제가 아닌 생활관리 선택지로 연결한다. 맞는 제품이 없으면 연결하지 않으며, 제품을 갑자기 꺼내거나 구매를 강요하지 않는다.

## 입력에 따른 작성 모드

- 실제 상품명·상세정보·링크가 없으면 건강정보 글을 먼저 완성한다. 본문 행동과 직접 맞고 사용 장면·장점이 분명한 제품이 있을 때만 마지막에 `제품 후보: **제품 카테고리 1개**`를 두며, 없으면 제품 문구를 생략한다. 쇼핑커넥트 고지와 링크를 만들지 않는다.
- 실제 상품명·상세정보·링크가 있으면 확인된 상품 특징만 사용해 제품 선택 기준과 CTA를 작성한다. 본문 최상단에 쇼핑커넥트 고지를 정확히 한 번 둔다.
- 사용 경험이 제공되지 않았다면 직접 써보거나 먹어본 것처럼 쓰지 않는다. 대신 누구나 겪을 수 있는 생활 공감 장면을 1~2문장 쓴다.
- 제품 정보가 부족하면 기능·효과·인증·수치·후기를 만들지 않는다.

## 권장 글 구조

1. **문제 제기와 직접 답변**: 첫 1~2개 짧은 문단에는 독자가 실제로 겪는 시간·장소·행동과 불편을 보여 준다. 이어지는 문단에서 핵심 질문에 직접 답하고, 증상만으로 질환을 단정하지 않는다. 서론 전체는 2~4문단 안에서 끝내며 제품명은 앞세우지 않는다.
2. **필요할 때만 핵심 체크**: 긴 글의 판단 기준을 미리 보여 주는 편이 이해에 도움이 될 때만 `이 글에서 확인할 핵심 N가지`를 한 번 둔다. 제목이 숫자를 약속했다면 같은 숫자로 맞추고, 본문과 중복되거나 흐름을 끊으면 생략한다.
3. **증상과 확인 기준**: 독자가 자기 상태와 비교할 수 있도록 증상이 나타나는 시간·양상·빈도·동반 변화를 설명한다. 긴 질환 정의와 출처 나열은 피한다.
4. **가능한 원인과 악화 요인**: 흔한 원인, 생활 습관, 환경 요인을 구분해 설명하되 하나의 원인으로 확정하지 않는다. 원인 설명 중간에 해결책을 섞어 흐름을 끊지 않는다.
5. **해결 방법 및 생활 대책**: 안전하고 바로 가능한 행동 2~4개를 구체적으로 제안하고, 언제 중단하거나 조정해야 하는지도 함께 알린다. `제품부터 사기 전에`, `돈 쓰기 전에`, `굳이 사지 않아도`처럼 구매 의욕을 꺾는 소제목은 쓰지 않는다.
6. **제품이 필요한 생활 장면(선택)**: 집·직장·외출·식사 준비 등 반복되는 환경에서 제품이 실제로 줄여 주는 불편이 있을 때만 쓴다. 제품보다 생활 대책을 먼저 설명하며 맞는 제품이 없으면 이 구간을 생략한다.
7. **장점과 실제 쓰임(선택)**: 제품의 확인 가능한 핵심 장점이 어떤 불편을 덜고 어느 장면에서 쓰이는지 설명한다. 구매 기준을 길게 나열하지 않고 꼭 필요한 확인점 1~2개만 문장 속에 넣는다.
8. **위험 신호와 진료 기준**: 지속 기간, 통증·붓기·발열 같은 동반 신호, 일상 기능 저하 등 주제에 맞는 기준을 안내한다. 제품 설명보다 응급·진료 판단을 우선한다.
9. **생활 공감과 마무리 행동**: 교과서처럼 보이지 않도록 보편적인 생활 장면을 1~2문장 넣고 오늘 실행할 한 가지를 분명히 제안한다. 제공되지 않은 개인 경험은 창작하지 않는다.
10. **짧은 행동 마무리**: 오늘 할 행동 1~2개를 분명히 남긴다. 제품을 연결했다면 놓치기 쉬운 생활환경 → 핵심 장점 → 실제 사용 장면 → 비교 CTA로 자연스럽게 이어지고, 제품이 없다면 생활 행동으로 깔끔하게 끝낸다. 같은 병 설명을 반복하지 않는다.

## 제품 연결 원칙

- 건강정보 → 생활관리 → 반복되는 불편 → 제품 카테고리 필요성 → 핵심 장점과 실제 사용 장면 → 제품 확인 순서를 지킨다. 실제 상품 링크가 없는 지정 제휴상품 글에서는 번호형 구매 전 체크리스트를 만들지 않는다.
- 제품 연결 구간은 `남은 생활 불편 → 제품 없이 가능한 방법 → 반복할 때의 번거로움 → 제품이 단순하게 해 주는 과정 → 선택 기준` 순서로 쓴다. 제품이 치료하거나 증상을 해결한다는 인상을 주지 않는다.
- 비타민·영양제·건강식품은 생활도구와 다른 흐름을 사용한다. `현재 생활 문제 → 이럴 때 함께 챙겨볼 영양소 → 관련 음식과 실제 식사 구성 → 매일 고르게 준비하기 어려운 상황 → 식사를 보완하는 제품 선택지` 순서로 쓴다. 예: `이럴 때 식사에서 함께 챙겨볼 영양소로 비타민B군을 살펴볼 수 있습니다.` 영양성분 표시·1회 섭취량 같은 구매 기준부터 갑자기 꺼내지 않으며, 증상만 보고 영양 결핍이라고 단정하거나 제품이 증상을 개선한다고 말하지 않는다.
- 제품 선택 소제목에는 제품명이나 제품군을 바로 넣지 않는다. 앞의 생활 행동을 이어받는 질문으로 쓰고, 소제목 아래에서 반복되는 번거로움을 설명한 뒤 제품을 처음 언급한다.
- 제품명이나 제품군은 생활 질문형 제품 소제목 아래 본문에서 처음 등장해야 한다. 소제목 전에는 제품명 없이 남은 불편과 제품 없이 가능한 방법을 설명하고, 위험 신호·진료 기준 뒤에는 새로운 제품 설명을 시작하지 않는다.
- 기록 노트·건강 수첩·증상 일지·다이어리는 쇼핑 제품 후보로 연결하지 않는다. 기록이 필요하면 휴대전화 메모처럼 이미 가진 도구를 쓰게 하고, 제품 후보는 음식 준비·위생·수면 환경·자세·온도 조절처럼 실제 생활 행동을 직접 돕는 물건으로 고른다.
- 제품의 기능을 말할 때 `확인된 특징 → 줄어드는 번거로움 또는 얻는 실용성 → 잘 맞는 사람·상황`으로 설명한다.
- 제품이 질환을 치료·예방하거나 수치를 개선한다고 쓰지 않는다.
- 처방약·일반의약품을 구매 후보로 추천하지 않는다.
- 제품명을 필요 이상 반복하지 않는다.
- 건강정보 글은 자연스러운 제품 후보가 있을 때만 마지막 행동 문단과 두 줄을 띄운 뒤 `제품 후보: **제품명**` 한 줄을 둔다. 후보가 없으면 제품명 줄을 만들지 않는다.
- 사용자가 상품명만 지정하고 링크·상세정보를 주지 않은 경우에도 상품명을 먼저 꺼내지 않는다. 음식이나 비용 없는 생활관리로 연결 필요성을 만든 다음, `이럴 때 도움을 줄 수 있는 음식 또는 보완 선택지가 있다`는 문장으로 제품군을 소개한다. 확인되지 않은 특징은 만들지 않고 마지막에 `내 식사·사용 환경 확인 → 실제 표시사항·구성 비교 → 조건이 맞으면 구매 결정`으로 이어지는 CTA를 쓴다. 다음 별도 문단에는 `이럴 때 살펴볼 제품: **제품명**`을 둔다.
- 실제 상품 글은 `평소 사용 환경과 맞는지 비교해 보세요`, `이 기준에 맞는지 확인해 보세요`처럼 클릭할 이유가 있는 CTA로 링크에 연결한다.

## 서론 문체와 순서

### 사람말투 기본값

- 블로그 운영자가 독자에게 직접 설명하듯 쉽고 담백하게 쓴다. 기사 요약체, 제품 보고서, AI식 해석과 교훈적인 마무리는 쓰지 않는다.
- 확인된 사실과 필요한 실천법까지만 말하고, 사실 뒤에 매번 의미·평가를 덧붙이지 않는다.
- `눈길을 끕니다`, `인상적입니다`, `참고할 만합니다`, `필요는 없겠죠`, `생각이 들었습니다` 같은 상투어로 문단을 닫지 않는다.
- `단순히 A가 아니라 B`, `A로만 보기보다 B에 주목` 같은 해설형 문장틀과 `~했는데요`의 연속 사용을 피한다.
- `합니다`, `됩니다`, `나타납니다` 같은 현재형 `~ㅂ니다`로 문장을 줄줄이 끝내지 않는다. `~해요`, `~있어요`, `~라고 해요`를 문맥에 맞게 섞고, 이미 일어난 일은 과거형으로 쓴다.
- 정보가 부족하면 비슷한 말을 늘리지 않는다. 건강상 필요한 개인차·금기·진료 기준은 대상과 조건을 구체적으로 쓴다.

- `아침에 침대에서 내려왔을 때`, `출근 준비를 하다`, `식사 뒤`, `밤에 누웠을 때`처럼 주제와 맞는 구체적인 생활 순간으로 시작한다.
- 첫 장면은 1~2문장으로 짧게 쓰고, 다음 문단에서 `그렇다고 ○○만으로 △△라고 단정할 수는 없습니다`처럼 검색 질문에 자연스럽게 답한다. 응급성이 높은 주제는 생활 장면 직후 무엇을 우선해야 하는지 분명히 알린다.
- 답변 다음에는 이유를 짧게 설명하고 `언제 심한지, 무엇과 함께 나타나는지, 평소와 무엇이 달라졌는지부터 살펴보세요`처럼 글에서 확인할 범위를 안내한다.
- `먼저 답하면`, `결론부터 말하면`, `정리부터 하면` 같은 기계적인 시작 문구를 쓰지 않는다.
- 질환 정의, 기관 설명, 위험 신호를 첫 문단에 한꺼번에 몰아넣지 않는다. 핵심 요약이 꼭 필요할 때만 서론 뒤 한 번 사용하고, 그렇지 않으면 증상과 확인 기준으로 바로 이어 간다.

## 제목 생성과 유지

- 뉴스나 블로그 자료에서 글감 후보를 만들 때는 원문 제목을 그대로 복사하거나 어미·문장부호만 바꾸지 않는다. 정보형, 고민형, 상황형, 판단 기준형 가운데 주제에 맞는 형식을 쓰고 후보 5개에는 최소 3가지 유형을 섞는다. 정보형은 `무릎관절염 체중 관리, 식생활과 부담 적은 운동`처럼 핵심 검색어와 구체적인 내용을 바로 보여준다. 고민형·상황형은 실제 생활의 불편과 해결 방향을 함께 보여주며 물음표를 사용할 수 있다. `원인과 관리방법`, `원인과 생활 관리방법`, `생활 관리방법과 진료 기준`처럼 어느 건강 글에나 붙는 표현과 같은 어미의 반복은 금지한다.
- 사용자가 글감을 선택하면 그 제목을 최종 제목으로 확정한다. 본문 작성 중 더 좋아 보이는 검색어를 붙이거나 문장을 다듬는다는 이유로 변경하지 않는다.
- 네이버 임시저장, 대표이미지 문구 선정, 이미지 저장 폴더 생성, 2차 임시저장까지 같은 글감 제목을 글자 하나까지 유지한다.

## 실제 상품 글 고지

실제 네이버 쇼핑커넥트 상품과 링크를 넣는 글은 본문 최상단에 다음 문구를 정확히 한 번 둔다.

`이 포스팅은 네이버 쇼핑 커넥트 활동의 일환으로, 판매 발생 시 수수료를 제공받습니다.`

상품이나 링크가 없는 제품 후보 글에는 고지를 넣지 않는다.

## 표현 안전

- 피한다: `이 증상은 ○○병입니다`, `이 제품이 치료합니다`, `염증을 없앱니다`, `혈당을 낮춥니다`, `질환을 예방합니다`.
- 사용한다: `이런 양상에서 나타날 수 있습니다`, `증상만으로 단정하기 어렵습니다`, `생활관리 선택지로 비교할 수 있습니다`, `제품 선택 시 ○○ 구조를 확인해 보세요`.
- `지금 당장 구매하세요`, `무조건 추천`, `꼭 사야 합니다`, `이 제품이면 해결됩니다` 같은 강매 문장을 쓰지 않는다.
- 지나친 불안과 공포를 만들지 않는다. 심하거나 지속되는 증상에는 적절한 진료 안내를 둔다.

## 반복 제거

완성본을 내기 전에 같은 증상 설명, 생활관리 방법, 제품 선택 기준, 진료 권고, 제품 필요성, 결론이 반복되는지 확인한다. 같은 의미가 두 번 이상 나오면 한 번으로 합친다. 긴 질환 정의와 없어도 이해되는 연결 문장을 우선 줄인다.

- 한 문단은 1~4문장으로 쓰고 모바일에서 길게 뭉치지 않는다.
- 하나의 소제목에는 하나의 메시지만 둔다.
- 같은 내용을 굵은 글씨·소제목·결론에서 반복 강조하지 않는다.

## 이미지와 해시태그

- 대표이미지, 증상이 나타나는 생활 장면, 원인·식사 구성 장면, 집에서 실천하는 장면을 글 흐름에 맞게 제안한다. 제품이 연결된 글만 제품 사용 장면을 추가한다. 같은 식탁·인물·소품·카메라 구도를 반복하지 않고 각 이미지가 바로 앞뒤 문단의 한 가지 내용을 구체적으로 보여 주게 한다.
- 건강 이미지는 공포감을 과도하게 조성하지 않는다.
- 해시태그는 핵심 증상 2개, 생활관리 2개, 제품 카테고리 1개, 검색 확장 1개를 섞어 정확히 6개를 글 맨 아래에 둔다.

## 최종 검사

1. 첫 2~4문단이 생활 장면에서 시작해 검색 질문에 자연스럽게 답하는가?
2. 건강정보를 얻었다고 느낄 만큼 설명했는가?
3. 제품 없이도 독자의 문제를 해결할 만큼 본문이 충실한가?
4. 제품이 있다면 생활 속 필요성이 먼저 생기고 치료제가 아닌 보조 선택지로 보이는가?
5. 실제 상품 정보에 없는 기능·효과·후기를 만들지 않았는가?
6. 제품이 있다면 핵심 장점과 실제 사용 장면이 구체적인가?
7. 같은 설명과 결론을 반복하지 않았는가?
8. 제품이 있다면 CTA에 비교할 구체적인 이유가 있고, 제품이 없다면 실천 행동으로 자연스럽게 끝나는가?
9. 위험 신호와 진료 기준이 제품 설명보다 우선하는가?
10. 해시태그가 정확히 6개이며 글 맨 아래에 있는가?
11. 선택한 글감 제목이 포스팅 제목과 글자 하나까지 같은가?
